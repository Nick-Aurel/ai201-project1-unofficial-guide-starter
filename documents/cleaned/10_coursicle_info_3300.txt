COURSE: INFO 3300

INFO 3300 - Visual Data Analytics for the Web (formerly Data-Driven Web Applications)
Credits: 3
Usually held: MWF (11:15am-12:05pm), MWF (11:20am-12:10pm)

COURSE DESCRIPTION:
This course covers technologies for representing, modeling and displaying data in the context of interactive web pages. Practical skills for building web pages are mixed with data mining algorithms and visualization design theory. Students use the D3 Javascript library to develop static and dynamic visualizations, learn Javascript programming, and explore web scalable vector graphics (SVG). Application required for enrollment.
